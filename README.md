# SkillSwap

SkillSwap is a creator gig marketplace where independent creators publish services and clients discover, request, and track creative work.

## Track and stack

Creator Economy brief · Vanilla JavaScript, CSS, and Vite.

## Run locally

```bash
npm install
npm run dev
```

No login is required. The app runs entirely in the browser and keeps demo data in local storage.

## Demo flow

1. Browse or search the marketplace and open a gig.
2. Request a booking; it appears in **My bookings** as Pending.
3. Post a gig, then book that gig from Explore.
4. Open **Creator dashboard** to accept or decline incoming requests.
